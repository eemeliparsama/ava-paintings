# Fonts

The fonts are stored here on the site itself, so visitors' browsers never contact
Google or Fontshare (no visitor data goes to them, and pages load a little faster).
They are set up in `css/fonts.css`.

- **Cormorant Garamond** (headings), weights 500 and 600 in one variable file, split into
  basic Latin (covers English and Finnish) and extended Latin. From Google Fonts.
  Licence: SIL Open Font License 1.1, see `OFL-Cormorant-Garamond.txt`.
- **Switzer** (body text), weights 400 and 500. From Fontshare by the Indian Type Foundry.
  Licence: ITF Free Font License, free for personal and commercial use including websites:
  https://www.fontshare.com/licenses/itf-ffl
